# 銀行債券抽取 — 定位層重寫計劃 v2(定案版)

> 骨架:**形狀篩摘要 → LLM 回頁碼 → 影像讀值 → 程式對帳**。
> 單一資料來源=明細表;BS 只當對帳外錨;主附註整條刪。
> 定位只負責「框到頁」,讀值一律截圖交 Gemini,文字湯/掃描圖天然繞過。零版型門檻、零特例。
> 以下每條都經 pdf_cache(80 份)實測。

## 0. 口徑與欄位(已定)
- **口徑**:一律銀行**個體**(5835/5836/5841/5843/5847),不混金控合併(如 2891)。
- **要的欄位 → 唯一來源**:

  | 類別 | 要 | 值名稱 | 來源 |
  |---|---|---|---|
  | Trading | 成本 + 公允 | 取得成本 + 公允價值 | 明細表二 |
  | OCI | 成本 | 取得成本 | 明細表三 |
  | AC | 成本 | 帳面金額(=攤銷後成本,暫定) | 明細表四 |

- **缺欄 → 直接 NA**,不兜底、不回退主附註、不硬湊。
- **主附註不使用**(輸出、兜底、對帳三個角色全歸零 → 整條刪)。

## 2. 定位規則(唯一通用律)
> **有文字層 → 形狀篩摘要交 LLM 找頁;無文字層 → 靠固定位置 + 視覺。**

**摘要用「形狀」篩,不用「位置」篩**:
- 掃整頁每一行,只留「像標題」的:**短行(<40字,軟啟發式)且含編號(六(三)/九、/(四)/表三…)或關鍵詞(明細表/透過損益/透過其他綜合/攤銷後成本/資產總計…)**。
- 丟掉:長行、數字逗號成串的行(表格內文=湯)。
- 效果:①標題在頁中/頁尾都撈得到(位置無關);②湯是長數字行,被形狀篩自動丟。

## 3. 流水線(四步)
```
① 形狀篩摘要:逐頁抽「標題形狀的行」(全頁掃、濾湯)→ 精簡目錄(頁碼 + 標題行)
② 定位:
   - 明細表(難、會湯/變格式)→ 一次 LLM 回 {Trading, OCI, AC} 頁碼
   - BS(易、確定)→ 不勞 LLM:grep「資產總計/資產合計」;老富邦零文字 → 前段固定位置
③ 截圖那幾頁 → Gemini 視覺讀值 + 分桶(Trading 雙欄取得成本/公允、OCI/AC 成本欄)
     └ 三類連頁 → 落一張,鄰頁一起截;缺欄該格 NA
④ 三道保險絲對帳(訊號全來自明細表自身 + BS,不碰主附註):
     - 內部:對帳總額 == 明細表印出合計
     - 段小計自洽
     - 外錨:對帳總額 == BS 該類金額(Trading/OCI 用公允欄、AC 用帳面欄)
   對不過 → 鄰頁 ±擴張重讀;仍不過 → fail-loud 待人工

   兩種總額(D,衍生只出現在 Trading;OCI/AC 無衍生→兩總額自動相等):
     · 分桶總額(輸出用)= 各債券/股票桶,排除衍生
     · 對帳總額(核帳用)= 分桶總額 + 衍生公允 → 才拿去比合計/BS
   成本錨(A):取得成本無外錨,但明細表印「取得成本合計」→ 內部自核;
             搭公允→BS 證明「落對表」,成本同表故可信。

   分桶後盾(第2級):另讀主附註各桶小計 → 明細表各桶加總 ==? 主附註小計
     對不上 → 指出錯桶示警;主附註粒度不足處退段落一致性檢查。
```

- **主附註:窄角色保留(第2級)**。不輸出、不當資料來源、不做總額對帳——**只讀「各桶小計」當分桶逐桶證人**。

## 5b. 分桶:規則 LLM 分類 + 第2級算術後盾(已定案)

**分類 = LLM 用規則判(不補關鍵詞字典)**:
只固定 9 個桶名(不會長大的標籤表):`公債/貨幣市場/公司債/金融債/資產基礎/可轉讓定存單/其他/股票/調整項`。
給**會計意義規則**讓 LLM 把任何品名塞進其一(新品名不用改任何清單):
```
政府公債→公債;國庫券/商業本票/承兌→貨幣市場;可轉讓定存單→可轉讓定存單;
金融機構發行→金融債;一般企業(含可轉換)→公司債;證券化/ABS/MBS/REITs→資產基礎;
權益(股票/受益憑證/基金/特別股/存託憑證)→股票;衍生/評價/備抵/減損/溢折價→調整項;
判不準(如國外機構債,發行人不明)→其他,並標記不確定
```

**分桶後盾 = 第2級「主附註逐桶證人」(已選)**:
> ⚠️ 對帳(總額)對分桶免疫——歸錯桶總額照樣對。故分桶需獨立後盾。

主附註本身**按桶列小計**(唯一獨立的逐桶數字)→ 算術核對:
```
明細表各桶加總(Trading/OCI 用公允、AC 用帳面) ==? 主附註各桶小計
  對得上 → 分桶算術證明正確(非靠 LLM)
  對不上 → 指出哪個桶被歸錯,示警人工
  公允桶對 = 該列歸桶對 = 同列成本桶也連帶正確
```
- 主附註定位:BS 附註編號(六(三)/九/十)→ 中段連頁(穩路);半年報亦有主附註。
- **粒度退化處理**:主附註若只印「債務/權益」層小計、未細分到桶 → 該處退回**段落一致性檢查**
  (權益工具段→必為股票、債務工具段→非股票),粗錯仍抓得到。

模型用**會計意義**歸桶(非字面)。

| 桶 | 命中品名(關鍵詞) |
|---|---|
| 公債 | 政府公債、中央政府公債 |
| 貨幣市場 | 國庫券、商業本票、承兌匯票、短期票券 |
| 可轉讓定存單 | 可轉讓定期存單、可轉讓定存單、央行定期存單 |
| 公司債 | 公司債、可轉換公司債 |
| 金融債 | 金融債券、金融債、次順位金融債 |
| 資產基礎 | 資產基礎債券、資產基礎證券、證券化商品、不動產抵押貸款證券、REITs |
| 股票 | 上市櫃/興櫃/未上市櫃股票、國外股票、受益憑證、基金、股票及基金、特別股、存託憑證 |
| 其他 | 其他證券及債券、國外機構發行債券*、其他 |
| 調整項(不入桶) | 衍生(利率交換/遠期外匯/選擇權/換匯換利/期貨)、評價調整、備抵損失、累計減損、未攤銷溢折價、應計利息 |

*`國外機構發行債券` 發行人性質字面判不準 → 歸「其他」+ 交叉示警,人工複核。REITs 暫歸資產基礎(可調)。

## 6. 已知風險(誠實列著)
- **半年報成本欄不齊 → 已定調 NA**:盤點表標明哪幾格 NA,供對照。
- **「連號連頁」尚未全驗**:LLM 本就回各類各自頁碼,不連頁也各自定位得到,連頁只是省事的加分,非架構前提。
- **「成本」定義不一致**:AC=帳面(攤銷後成本)暫定,先放著。
- **形狀篩 `<40字` 是軟啟發式**:誤篩只讓 LLM 摘要略髒(可容錯),非舊 `thresh` 那種「讓整頁隱形」的硬門檻;§5 微調。
- **真死角**(80 份內未見):整份 100% 圖 + 無 TOC + 章標題全湯 → 才會落不準;即便如此對帳 fail-loud 擋住,不靜默出錯。
