# AC / OCI 配置分析 —— 發現彙整

範圍：五家台灣銀行（中信 5841、兆豐 5843、國泰 5835、富邦 5836、玉山 5847），
**一律個體口徑（AI3）**，2021–2025 年報。單位除另註明外為新臺幣億元。

> 證據等級標記：
> **【測】**直接量到,無假設 · **【恆】**恆等式,不是發現 ·
> **【弱】**n=5 不顯著或單點槓桿 · **【疑】**依賴不可靠的假設,見 §7

## 0. 定案框架：三個因子

一維解釋不了這五家。實際上有三個**互不相關**的因子：

```
結構因子(規模)  ──→  決定「藏不藏」        AC佔比 × 債券/RWA = +0.90        §2
偏好因子(自由)  ──→  決定「吃多少利率風險」  與所有結構變數 |ρ| ≤ 0.6        §3
資本因子(受限)  ──→  決定「擴不擴、往哪擴」  年初CET1 × Δ(債券/RWA) = -0.60  §4
                                          但 × AC佔比 只有 +0.20
制度約束        ──→  五家一視同仁,解釋不了差異                            §5
```

- 資本管的是**量**（要不要用債券擴表），不管**分類**（擴了之後放哪個桶）。
  這解釋了為什麼「資本 → 配置」怎麼測都測不出來。
- 偏好因子是自由的：2022 年總跌幅與**所有**結構變數都不相關
  （平均 CET1 +0.00、債券總成長 +0.00、OCI 中股票 +0.00、債券/RWA −0.20）。

偏好因子本身還可以再拆成兩種**互相替代**的風險（信用 × 利率 Spearman −0.50）——
問題不是「誰比較敢冒險」而是「敢冒哪一種險」，見 §3。

**全文唯一通過統計檢定的是 §4**（n=20，t=3.18），其餘全部是 n=5 的描述。

> **兩個閱讀前提**：
> ① 所有數字用 `git show HEAD:data.json`，working tree 版有 23 處分桶不一致（§1）。
> ② 所有指標的公式、符號、假設與敏感度在 **§11 附錄**。

## 1. 資料與驗收

| 資料 | 來源 | 驗收 | 結果 |
|---|---|---|---|
| 債券部位（帳面／成本，AC/OCI/Trading × 券種） | `data.json`，v3 管線 | 管線既有閘門 | — |
| 資本適足（CET1／T1／T2／RWA） | `capital_auto.py` 抄 202204–202504 | 五道對帳 + 跨份重疊 | 20/20 通過，跨份 14 格全對 |
| 權益變動（法定／特別公積／股利／淨利） | 同上 | 三道檢查 | — |
| **AC 桶公允價值** | 年報「非以公允價值衡量之金融工具」附註 | 揭露帳面 == 明細表 AC 合計（tol 1%） | **24/25**，缺玉山 2021 |
| **綜合損益表**（利息／證券損益／淨利） | `--kind pnl` 抄表身 | 收入−費用==淨額、量級、null 非 0 | 20/20，25 格 |
| **證券利息收入** | 附註「利息淨收益」＋附表「利息收入明細表」 | 分項==小計、跨表==損益表 41000（**精確相等**） | 20/20，24 格 |

**AC 公允價值那道最有力**——兩邊完全獨立（公允價值附註 vs 投資明細附註）。

**玉山 2021 那格過不了，而且那是對的**：`facts/202104_5847` 沒有 AC，
而玉山 202204 的明細表**只印一個年度**（欄是總面額／未攤銷溢(折)價／備抵損失／帳面金額，
沒有年度欄），所以沒有第二來源。數字讀得到（307,138,136 ／ 307,761,164），
但沒有獨立對帳就不放行——放行才是製造恆真閘門。

**驗收在這一輪實際攔到重編**：富邦 202304 的 2022 欄回 810,564,489（重編後），
與明細表的 773,757,561 對不上 → 擋下。這正是下面那條裁示的獨立驗證。

**兩個抄表教訓（2026-08）**：

1. **表被「（接次頁）」切開時，少的那格不會報錯，只會讓分析悄悄少一年。**
   玉山的損益表跨**三頁**、兆豐 202204 跨兩頁**卻沒印「接次頁」**（直接接著排），
   富邦的公允價值表把前期欄整個放在續頁。`capital._follow()` 現在無條件多送一頁
   並跟著「接次頁」的鏈走。AC 公允價值原本缺的 4 格就是這樣缺的。
2. **閘門不可以跟工單打架。** 工單要求把富邦同時印的 AC／OCI 兩列相加填進
   `securities`，閘門卻只認「等於單一分項」，把它判成造假擋掉整份。
   `test_interest_accepts_two_securities_rows` 就是防這個。

### ⚠ 富邦 2022 是**重編**不是合併汙染（更正）

先前記成「富邦 202304 p108 回了 8106 是合併」——**誤判**。原文印的是
「111年12月31日（**重編後**）」，是日盛銀行併入造成的追溯重編：

```
             202204 原始      202304 重編後      差
AC 帳面      773,147,312      810,564,489     +374 億
利息收入      55,613,358       59,797,260     +7.5%
淨利          22,796,289       23,934,126     +5.0%
```

**一律用原始版**（登記在 `capital.RESTATED`）——不是因為它比較對，而是
`data.json` 的富邦 2022 是併前的 7,731 億，**兩邊必須同一把尺**，
否則「浮虧 = 公允 − 帳面」會把併購造成的規模跳動算成評價變動。
⚠ 一般情況是「後出的年報比較對」，這裡剛好相反，所以寫死不靠直覺。

### ⚠ 本文所有數字用 `git show HEAD:data.json`，不是 working tree

2026-08-05 14:58 有一次 `build.py` 重建把 `data.json` 改掉了（20/150 格變動）。
重建**同時**補上了 9 格缺失的 AC 成本、也引入了新的分桶不一致：

```
單邊分桶(同一筆在 wide 與 wide_cost 被分到不同桶)
HEAD 舊版     6 處  —— 幾乎都在 Trading(本文沒用)
working tree 23 處  —— 包含本文用到的 OCI 格
```

三處實質損害：
```
2021H2|玉山 OCI   金融債1309/公司債983/GB655 的成本全歸零(佔該類別94%) —— 純資料遺失
2022H2|富邦 OCI   受益證券82億:公允留在【股票】、成本被移到【資產基礎】
                  → 假浮虧 −2.15% 變 −10.24%(附註證實受益證券是權益工具)
2022H2|兆豐 OCI   66億:公允留在【其他】、成本被移到【貨幣市場】
```

**`build.py` 只驗總額，不驗 wide 與 wide_cost 的分桶是否對齊**，所以這類錯誤現在攔不到。
建議加一道閘門：對每個 (期別,銀行,類別)，若某券種在一邊 >0 而另一邊 ==0
且金額佔該類別 >2%，即為單邊分桶。

## 2. 結構因子：規模逼出遮蔽 **【測】**

```
銀行   AC佔比  OCI佔比  Trading | AC中貨幣市場  OCI中股票 | 債券/RWA  淨利
富邦   75.3%   19.1%    5.6%  |     31%        14%   |   34.0%   363
中信   70.7%   27.4%    1.9%  |     35%        13%   |   31.1%   573
國泰   38.4%   47.6%   14.0%  |     66%         8%   |   27.7%   430
玉山   25.8%   56.7%   17.5%  |     50%         8%   |   28.8%   328
兆豐   15.9%   76.8%    7.3%  |     88%        12%   |   18.0%   289
```

```
AC佔比      × 債券部位/RWA        Spearman +0.90
AC佔比      × AC中貨幣市場佔比      Spearman −0.90
AC中貨幣市場% × 債券部位/RWA        Spearman −1.00   ← 完全單調
```

**債券部位相對 RWA 越大的銀行，越把它放進 AC。**部位小的話全攤在 OCI 也不痛；
部位大到 RWA 的三分之一，就非藏不可。

第三條（完全單調）說的是另一件事：**「AC」這個科目在五家的用途根本不同。**
兆豐的 AC 有 88% 是央行定存單與短期票券——那是流動性水位；
富邦只有 31%，是真的債券。**兆豐拿它當現金池，富邦拿它當保險櫃。**

## 3. 偏好因子：吃多少利率風險是自由的 **【測】**

用 2022 年**含 AC 隱藏浮虧**的總跌幅衡量（直接量到，無假設）：

```
國泰 −11.60%   富邦 −7.50%   中信 −6.46%   兆豐 −5.27%   玉山 −4.42%

vs  平均CET1 +0.00   債券總成長 +0.00   OCI中股票% +0.00
    債券/RWA −0.20   AC中貨幣市場% +0.20   AC佔比 −0.60   淨利 −0.60
```

沒有一個過 0.6。**國泰是關鍵證據**：結構因子中等（債券/RWA 27.7%、AC 只用 38%），
偏好因子卻拉滿（總跌幅比第二名慘 55%）。

### 象限

```
                低曝險(利率)
   兆豐 · 玉山  │  （無人在此）
   「不下大注」   │  「藏一個沒風險的部位」
  ──────────────┼──────────────  AC佔比 50%
      國泰      │  中信 · 富邦
   「裸露承擔」   │  「重倉並遮蔽」
                高曝險(利率)
```

**右上角是空的——沒有人拿 AC 去藏一個其實很安全的部位。**AC 用得多的都是真的有東西要藏。

> ⚠ **縱軸只量利率風險，信用風險完全在軸外。**2022 是利率暴衝年，
> 一家用信用風險取代利率風險的銀行會被放在「低曝險」（見玉山）。

### 五家側寫

- **兆豐 — 不玩這個遊戲。** 債券只佔 RWA 18%，五年成長 +4%（別家 +42~57%）。
  AC 是流動性桶，真正的債券全攤在 OCI（美元短券，揭露值久期 1.5 年，最短）。
  OCI 裡 12% 股票、累積未實現 +231 億當墊子。資本最厚（13.06%）、淨利最薄（289 億）。
  **也是唯一沒有從貨幣市場轉進債券的一家（見 §4.4）。**
- **玉山 — 唯一真正換過方向的。** AC 佔比 11.0% → 39.7%（+28.7pt，全樣本最大變化）。
  CET1 最低（11.12%）。2022 總跌幅最輕（−4.42%）——
  **但那不是風險低，是風險擺在別的地方**：公債佔比 11.5% 全五家最低。
  ⚠ 精確講法：**它不是變得更冒險，是本來就最冒險而且沒有跟著別人回頭**——
  非公債佔比 2021→2025 只動 +1.4pt，同期富邦 −8.7pt、國泰 −7.8pt、兆豐 −5.6pt。
  而 `資產基礎 +16.7pt` 是**非公債內部的輪動**（金融債/公司債 → 證券化商品），
  不是從公債轉出來的。而且 2021 年最冒險的是富邦（89.0%）不是玉山（87.1%），
  **「玉山信用風險最高」只在 2025 這個時點成立。**
- **國泰 — 不藏卻承擔最多。** AC 裡 66% 是貨幣市場，它的 AC 也不是藏券的地方；
  Trading 佔 14%（最高），OCI 股票只有 7.8%（最少，最沒墊子）。
  所有壓力測試裡都最緊：0.7 碼就開始凍結盈餘。**最像投資部門說了算的一家。**
- **中信 — 藏了還敢露。** 重倉（債券/RWA 31.1%）、高 AC（70.7%），
  但淨利 573 億最厚、OCI 久期 4.7 年（揭露值）最長。公債佔比 42.8% 最高。
  **有本錢在看得見的地方也吃風險。**
- **富邦 — 藏了而且露出來的也要好看。** AC 佔比與債券/RWA 都最高，
  OCI 跌幅五年最溫和（−2.15%、−0.14%、−1.41%、+0.17%）。

### 兩種風險是**替代**，不是同向 **【測】**

券種組成就是信用風險偏好（2025 年底，分母同 §11 公式①）：

```
       公債    金融債    公司債   資產基礎     其他 | 非公債
玉山   11.5%   35.3%   27.1%   16.7%    9.4% | 88.5%
富邦   19.7%   31.2%   34.7%   11.6%    2.8% | 80.3%
兆豐   25.6%   26.7%   32.0%   15.8%    0.0% | 74.4%
國泰   36.3%   18.2%   24.0%   21.4%    0.0% | 63.7%
中信   42.8%   14.2%   18.0%   14.0%   11.0% | 57.2%
```

**「非公債佔比」不需要任何假設**（公債金額 ÷ 債券總額），
換三組風險權數假設重排，前後名次不變（只有國泰/兆豐在證券化權數 100% 那組互換）。
**所以直接用非公債佔比，不要用加權風險權數**——後者的絕對值是我假設出來的。

把它跟利率風險並排：

```
       信用風險(非公債%)   利率風險(22總跌幅)   承壓(到11%可跌)
玉山        88.5% 最高       −4.42% 最低        6.8% 最薄
富邦        80.3%            −7.50%           14.1%
兆豐        74.4%            −5.27%           24.8% 最厚
國泰        63.7%           −11.60% 最高       12.5%
中信        57.2% 最低        −6.46%            9.1%

信用風險 × 利率風險   Spearman −0.50
```

**負的。**玉山信用風險最高、利率風險最低；國泰反過來。所以問題不是「誰比較敢冒險」，
而是**「敢冒哪一種險」**：

```
玉山    信用 ↑↑  利率 ↓     用信用換利率
國泰    信用 ↓    利率 ↑↑    用利率換信用
中信    信用 ↓↓  利率 →     兩邊都保守,靠規模與淨利賺
富邦    信用 ↑    利率 ↑     兩邊都吃,但把利率那塊藏進 AC
兆豐    信用 →    利率 ↓     部位最小,不靠這塊
```

**穩健性**：信用風險含不含 Trading 排序完全一樣；利率風險換成 2025 年底
只有中信/兆豐互換，兩端（國泰最慘、玉山最輕）兩年都相同。

> ⚠ **報酬那一側做不出來。**`pnl.json` 只有銀行層級 NIM（主要由放款決定），
> 損益表沒有債券組合的利息收入拆分，也沒有持有殖利率揭露。
> **上表是單邊的風險量表，不是風險報酬比。**硬配報酬只能自己編利差。

## 3.5 報酬側：證券殖利率 **【測】**（2026-08 新增）

本文原本寫「報酬那一側做不出來，年報不拆債券組合的利息收入」——**那句是錯的**。
19/20 份年報在附註「利息淨收益」底下單獨揭露證券利息，`capital_auto.py --kind interest`
20/20 全過驗收（跨表閘門：附註小計 == 綜合損益表 41000，**精確相等不是容差**）。

### 口徑：分母不含 Trading，這件事會翻轉結論

附註自己寫「上表不含透過損益按公允價值衡量之金融資產或金融負債所產生者」
（中信／富邦明印；另三家把 Trading 利息放在 FVTPL 那個附註的獨立欄位）。
**分子既然排除 Trading，分母就必須是 AC+OCI。**

第一版把 Trading 放進分母，得到的結論整個是假的：

```
                    橫斷面極差        排名
分母含 Trading(錯)   0.14~0.31pt   兆豐最高 → 「冒險沒被補償、低風險異象」
分母只有 AC+OCI(對)  0.37~0.66pt   兆豐最低 → 相反
```

因為 Trading 佔比五家差很多（兆豐 4.5~5.1%、玉山 20~29%），含 Trading
等於**系統性懲罰 Trading 多的銀行**。

### 結果

| 銀行 | 2021 | 2022 | 2023 | 2024 | 2025 |
|---|---|---|---|---|---|
| 玉山 | 0.94% | **1.40%** | **2.24%** | **2.47%** | **2.60%** |
| 中信 | — | 1.34% | 2.21% | 2.40% | 2.56% |
| 國泰 | 1.30% | 1.15% | 1.81% | 2.28% | 2.26% |
| 兆豐 | 0.77% | 1.03% | 1.91% | 2.06% | **1.94%** |

**玉山連四年第一、兆豐連四年墊底。** 方向與 §3 的偏好框架一致：玉山買信用、
中信買久期（揭露 4.7y）、兆豐兩個都不買（揭露 1.5y）。

中信 2021 空白是資料缺口——`data.json` 沒有中信 2020H2 部位，算平均部位需要期初。
富邦不在表內：它 2021/2022/2025 只揭露 AC 桶利息（1.27% / 1.89% / 3.12%），
2023/2024 的附註才同時印兩桶（3.01% / 3.27%）。**逐年口徑不同，不可與上表並列。**

### 分桶殖利率：富邦是唯一組合解釋不了的一家 **【測】**

國泰與玉山的附表「利息收入明細表」把證券利息再拆成 AC／OCI 兩列
（中信與兆豐的同名附表只寫「請參閱附註」，本來就沒有，不是抄漏）。

| | AC 殖利率 | OCI 殖利率 | 貨幣市場佔比 AC ／ OCI |
|---|---|---|---|
| 玉山 2024 | 1.94% | **3.23%** | 60.5% ／ 0.0% |
| 國泰 2024 | 2.15% | **2.54%** | 57.8% ／ 0.0% |
| 富邦 2024 | **3.32%** | 3.07% | 30.7% ／ 0.0% |

國泰與玉山「OCI 比 AC 肥」**完全是組合造成的**——它們的 AC 有 50~72% 是定存單、
OCI 幾乎 0%。那不是選券，是 AC 桶被當成流動性水位（§8 早就記過這件事）。

**富邦反過來，而且方向穩健。** 它的 AC 有 31% 貨幣市場、OCI 是 0%，
照理 AC 該比較低，結果 AC 反而高 0.25~0.49pt。
「貨幣市場殖利率低於債券」這個假設**只會讓差距更大**，所以這個推論不需要
任何外生常數——不像 §7 那些被魔術常數打敗的嘗試。

→ **§3「富邦＝保險櫃」的定位，第一次在報酬側被獨立證實**：
它真的把肥券放進看不見的那一桶。這是全文唯一一條風險側與報酬側互相印證的發現。

### 這一節不能拿去說什麼

- **n=4，沒有任何統計檢定。** 排名穩定（玉山連四年第一）只是描述。
- **貨幣市場的混淆沒有解開。** 兆豐的 AC+OCI 有 58% 是定存單、中信 27%，
  兆豐墊底有多少是「不冒險」、多少是「一半是定存單」，分不開。
  試過用 `y = w·y_mm + (1−w)·y_bond` 拆，`y_mm` 從 1.7% 改成 1.4%，
  中信與兆豐的差距就從 0.29pt 塌到 0.08pt ——**結論隨假設翻，不要做**。
- **這只是利息，不是總報酬。** 處分損益與評價損益在綜合損益表上（見 `capital.json`
  的 `pnl`），還沒併進來。FY2025 光評價一項兆豐 +74.5 億、中信 +5.0 億，
  差距在這一節沒涵蓋的地方。

## 4. 資本因子：擴不擴、往哪擴 **【測，全文唯一顯著】**

### 4.1 面板結果

```
n = 20（5 家 × 4 個年度轉換）
年初 CET1  vs  當年 Δ(債券/RWA)      Pearson −0.60   t = 3.18 (df=18)
                                     臨界 |t| > 2.10 (α=.05) / 2.88 (α=.01) → 兩者皆過
```

**資本薄的銀行，接下來一年把債券部位相對整家銀行推得更高。**

**通過三個檢定：**

① **方向** —— 用年初資本預測當年擴張，不是事後相關。−0.60。

② **反向因果排除** —— 擔心「擴表 → RWA 上升 → CET1 下降」造成假相關：
```
當年債券成長  vs 當年ΔCET1   −0.06   ← 幾乎沒有
超額成長     vs 當年ΔCET1   +0.41   ← 方向是反的
當年RWA成長  vs 當年ΔCET1   −0.64   ← 這個才是機械的(整體擴表確實吃資本)
```
債券擴張**不會**壓低當年 CET1。機械故事不成立。

③ **銀行固定效果** —— 組內去平均後 **−0.66（t=3.25）**。
同一家銀行，在它自己資本較薄的那些年，債券擴張得比較兇。

### 4.2 它的弱點

```
留一年法              留一家法
−2022  −0.30  t=1.15  ← 不顯著     −富邦 −0.60  −中信 −0.48(t=2.07,勉強)
−2023  −0.77  t=4.38               −國泰 −0.58  −玉山 −0.81  −兆豐 −0.58
−2024  −0.61  t=2.80
−2025  −0.61  t=2.75
```

**拿掉 2022 就沒了。**所以這主要是**衝擊年**的現象，不是跨期通則。

**統計保留：n=20 但只有 5 個群集。**年度觀測在銀行內不獨立，
用群集標準誤的話有效自由度只剩 4，t=3.18 會大幅縮水。組內檢定部分處理了這件事。

**口徑警告：**「債券總成長 vs 平均CET1」在 AC+OCI 口徑是 −1.00、
把 Trading 算進去就掉到 −0.10。**那個 −1.00 口徑一換就垮，不要用。**
穩的是超額成長（−0.90）與 Δ(債券/RWA)（−0.90），兩者用全部三桶。

### 4.3 擴表的機制：資本是預算，風險權數是價格

```
CET1 比率 = CET1 ÷ RWA ≥ 門檻   →   RWA ≤ CET1 ÷ 門檻   ← RWA 就是預算

同樣 100 億吃掉的預算(標準法)        同樣 100 億 RWA 預算能買
企業放款(未評等) 100%  → 100 億      企業放款      100 億
住宅房貸          45%  →  45 億      住宅房貸      222 億
投資等級公司債     50%  →  50 億      投資等級公司債  200 億
金融債(本國銀行)   20%  →  20 億      金融債        500 億
公債/央行定存單     0%  →   0 億      不吃風險性資產預算(改受槓桿比率限制)
```

**融資端在台灣不是限制**——本國銀行存放比長期低於 80%，存款收進來沒地方放。
瓶頸是「資本夠不夠掛」，這也是為什麼台灣銀行手上堆著幾千億央行定存單。

### 4.4 但這五家做的不是擴表，是輪動

```
債券佔「有價證券」的比重(其餘為貨幣市場)
銀行    2021   2022   2023   2024   2025   21→25
中信     45%    50%    52%    53%    62%  +16.7pt
玉山     47%    54%    56%    58%    60%  +13.5pt
國泰     39%    39%    47%    58%    49%  +10.6pt
富邦     58%    63%    68%    68%    67%   +9.2pt
兆豐     42%    48%    46%    46%    41%   −0.3pt
```

**2022 那年五家全部同向轉進債券**（+0.7 ~ +7.5pt）。逐筆看 2021→2022：

```
銀行  CET1率21 |  RWA增加   債券增加  貨幣市場增加
玉山   10.32% |   +659億   +819億      −676億   ← 債券增加比 RWA 還多
國泰   12.56% |  +1769億   +177億       +87億
富邦   12.26% |  +1485億   +369億      −471億
中信   14.97% |  +3533億   +575億      −651億
兆豐   12.97% |   +816億   +229億     −1064億
```

玉山的債券**不是新增資產，是從貨幣市場換過來的**。而央行定存單權數 0%、債券 20~50%，
**這個換法是消耗資本不是節省資本**——玉山那年 CET1 從 10.32% 掉到 10.07%，正是代價。

### 4.5 修正後的機制：受限之下追殖利率

```
資本薄  →  ① 整體資產成長受限（年初CET1 vs RWA成長 +0.37）
        →  ② 但獲利壓力還在
        →  ③ 在被綁住的資產負債表裡,把零收益的央行定存單換成債券
        →  ④ 債券/RWA 上升,而且是花掉資本換來的
```

文獻裡這叫 **reaching for yield**——
[Becker & Ivashina (2015)](https://www.nber.org/system/files/working_papers/w18909/w18909.pdf)
的核心發現是「受監理約束的機構會在合規範圍內挑收益率最高的標的」；
[後續研究](https://www.sciencedirect.com/science/article/abs/pii/S0378426623002212)
指出風險權數制度會誘導機構囤積「權數低但實質風險高」的資產。

**券種移動的證據對得上**（2021→2025 佔比變化 pt）：

```
銀行        GB      金融債     公司債    資產基礎
富邦     +8.9    −0.4    −12.8    +10.2
中信     −0.2   −10.0     +3.5     +0.9
國泰     +7.8    −9.8     −7.1     +9.1
玉山     −2.6    −9.5    −11.3    +16.7
兆豐     +5.5    −1.4     −7.5     +3.4
```

**五家全部減金融債、五家全部加資產基礎（證券化商品），方向零例外。**
同一個動作的兩個切面——往期限走，也往信用走。

### 4.6 這一節的邊界

- 「reaching for yield」是我從行為反推的標籤，不是這五家說的。要確認得看法說會或投資政策文件。
- 券種權數用的是標準法教科書值。`capital.json` 五家的「內部評等法」欄位都是 0，
  推測都用標準法，但**沒有另外查證**。
- **有一個更簡單的競爭解釋**：2022 之前利率太低，債券根本不值得買，
  所以輪動只是利率環境正常化，跟資本無關。
  **全體同向的東西，橫斷面測不出來**——這正是拿掉 2022 後 −0.60 掉到 −0.30 的原因。
- 兆豐是明確反例（資本最厚、完全沒轉），與「受限才追收益」一致，但 n=1 不算驗證。

## 5. 制度約束：真實、會咬，但解釋不了差異

### 5.1 機制 **【恆】**

```
債券跌價 ├─ 放 OCI → 其他權益 ─┬─ ① 全額扣 CET1（台灣無 AOCI 豁免）
         │                    └─ ② 其他權益轉負 → 提特別盈餘公積，凍結等額盈餘
         └─ 放 AC  → 帳上完全沒有 → ①② 皆不發生；代價是實質賣不得
```

台灣特有：**無 AOCI 豁免 ＋ 特別盈餘公積 ＋ 配發率 ~100%** → 浮虧一比一凍股利，
不經監理裁量。英文文獻沒有這條通道。

**四個規則沒要求、他們選擇這樣做的行為** —— 這才是實證內容：
① 配發率 ~100% ② 解凍後不還給股東（法規是「得」不是「應」）
③ 五年沒有人賣過 AC ④ 曝險差 2.6 倍

### 5.2 配息線比資本線早 5~17 倍到 **【測】**

2025 年底、個體口徑：

```
銀行  CET1率   到9%可跌  到11%可跌  配息線可跌 | 換算利率(到11%/配息線)
中信  11.91%    29.0%     9.1%      1.2%    |  454bp /  58bp
兆豐  14.16%    40.4%    24.8%      3.4%    |  952bp / 129bp
國泰  12.67%    27.4%    12.5%      0.7%    |  312bp /  18bp
富邦  12.07%    40.7%    14.1%      5.3%    | 1285bp / 481bp
玉山  11.99%    20.4%     6.8%      1.2%    |  375bp /  66bp
```

對照 2022 實際 OCI 跌幅（−2.10% ~ −7.86%），**五家有四家穿過配息線，
資本適足率連邊都沒碰到**。

### 5.2b 承壓能力：CET1 能吸收 OCI 跌多少 **【測】**

```
      CET1億    RWA億   CET1率   OCI債券 | 到11%緩衝    可跌 | 到法定緩衝    可跌 | AC按市值後可跌
兆豐    3600   25424  14.16%   3246億 |   +804億  24.8% |   1312億  40.4% |        24.4%
富邦    2904   24065  12.07%   1813億 |   +256億  14.1% |    738億  40.7% |        −0.5%
國泰    2932   23142  12.67%   3101億 |   +387億  12.5% |    849億  27.4% |         4.3%
中信    3396   28511  11.91%   2865億 |   +260億   9.1% |    830億  29.0% |         2.7%
玉山    2743   22873  11.99%   3364億 |   +227億   6.8% |   1142億  33.9% |         3.7%
```

**排序在最後一欄整個翻掉。**用帳面看富邦第二耐打（14.1%）；
把 AC 隱藏浮虧（−265 億）補回去，它變成 **−0.5%，已經在線下**。
兆豐兩種算法都第一（AC 只藏了 10 億）。

法定線：D-SIB 四家 9%、玉山 7%。**玉山「到法定 33.9%」看起來寬是因為它的線低 2pt，
不是它比較安全**——同樣用 11% 比，它是最薄的（6.8%）。

分母只放 OCI：**AC 跌價不進 CET1**，所以問「CET1 能吸收多少」時它不該在分母裡。

> **口徑警告**：11% 法規上套在**合併**。合併口徑為中信 11.14%、國泰 11.72%、
> 玉山 11.58%、**富邦 10.64%（已在線下）**。合併口徑的債券部位只有中信有。

### 5.3 為什麼這些指標當不了自變數 **【測】**

**第一類：部位的改寫。** `每碼吃淨利 = OCI部位 × 久期 ÷ 淨利`，
而 `OCI部位 = (1−AC佔比) × 總部位`。

```
每碼吃淨利% × AC佔比 −0.90    每碼CET1掉 × AC佔比 −0.70    股利CV × AC佔比 −0.80
每碼吃淨利% × 每碼CET1掉 +0.90   ← 這兩個根本是同一個變數
```
相關很高，但那是把同一個數字換寫法再跟自己相關。**不是發現。**

**第二類：真正的距離（緩衝 ÷ 部位），跟什麼都無關。**

```
離11%可跌% × AC佔比 −0.10    × 2022總跌幅 −0.30
配息線可跌% × AC佔比 +0.19    × 2022總跌幅 +0.10
```
緩衝由整家銀行的獲利與 RWA 決定，**跟債券部門買多長的券各自獨立**。

> 約束是真的、會咬，但**咬所有人的方式差不多**。
> 「配息才是唯一實質約束」是台灣制度的性質，不是某家銀行的特徵。

### 5.4 鏈條斷在中間 **【測】**

```
A  OCI佔比 → 債券浮虧    成立(強)
B  債券浮虧 → 凍結       ✗ 斷點   浮虧 vs 凍結額 Pearson +0.12
B' 其他權益 → 凍結       成立(強)              Pearson −0.80
C  凍結    → 配息率       成立(中)              Pearson −0.54
端到端  OCI佔比 → 配息率                       Spearman −0.05
```

**法規盯的是「其他權益」整箱，不是債券浮虧。**同一個 OCI 桶裡的股票未實現利益是正的：

```
其他權益箱內(億)   債券浮虧   股票未實現   相加
兆豐 2022          −205       +85      −120
兆豐 2023          −178      +207       +29   ← 由負轉正
兆豐 2024          −197      +196        −1   ← 幾乎完全相消
```

兆豐 2023 債券躺著 −178 億浮虧卻**迴轉了 119 億**——不是債券漲回來，是股票撐正了箱子。
**2022 是唯一鏈路導通的一年**（股債齊跌，沒東西可抵銷）。

> 邊界：其他權益還含換算調整。中信 2022 債券+股票 = −56 億，
> 但其他權益實際 −191 億，**差 135 億在別的地方**。有其他權益餘額的紀錄只有 8 筆。

（經濟意義的模擬，不是合規判斷——實務上 AC 只要不賣就永遠不扣。）

## 7. 久期：做不出來 **【疑】**

三種嘗試全部不可靠：

1. **水準法**（浮虧率絕對值）→ 錯。水準 = 久期 × **累計**殖利率變動；
   AC 不能賣，2020 年買的低票息券一直躺著，浮虧大是因為**券老**不是久期長。
2. **衝擊法**（Δ浮虧率 ÷ Δy）→ 被幣別打敗。2022 年台灣央行升 0.625pt、Fed 升 4.25pt，
   **幣別組合不同的銀行面對的不是同一個 Δy**。我假設五家都是 2pt。
3. **稀釋修正**（乘 (1+g)/(1+g/2)）→ 修錯對象。週轉造成 6~34% 偏差，幣別造成 2.5 倍。

**驗證**：銀行自己揭露的權益敏感度與我的估計對不上，且兩家反向——

```
        揭露值反推   我的估計    倍數
中信      4.7 年     2.1 年   低估 2.3 倍
兆豐      1.5 年     2.7 年   高估 2.5 倍
```

反算對得起來：兆豐 OCI 2022 跌 5.44%，若久期 1.09y 則隱含 Δy = 5.0pt（≈美元）；
中信跌 4.25%，若久期 4.81y 則隱含 Δy = 0.88pt（≈台幣）。
**兆豐的 OCI 是美元券，中信是台幣券。**

**可用的乾淨來源只有銀行自己的敏感度揭露，而只有兩家可用**：
中信與兆豐有 `損益/權益` 分欄的 IFRS 7 敏感度表；國泰的權益欄是 0（只涵蓋交易簿）、
富邦只揭露盈餘觀點（NII）、玉山沒有這張表。**AC 桶的久期沒有任何一家揭露。**

> **結論：五家可比的 AC/OCI 久期，用公開資料做不出來。**
> 站得住的只有中信 4.7y 與兆豐 1.5y 兩個 OCI 久期。

## 8. 已推翻的說法（保留，因為錯誤本身有參考價值）

| 先前說法 | 為什麼錯 | 現在 |
|---|---|---|
| 「CET1 五家全擠在 0.9pt 內，自變數沒有變異」 | 只看 2024——五年最窄的一年 | 有變異但水準不對齊（§6.4） |
| 「資本線多了一個數量級，不在賽局裡」 | 只用法定 9%；目標線是 11% | 差 5~8 倍，合併口徑下富邦已在線下 |
| 「台灣的 AC 是流動性桶」 | 只看到貨幣市場佔比高 | **視銀行而定**——兆豐 88% 是，富邦 31% 不是 |
| 「AC 比 OCI 長 2~5 倍」／「AC 是槓鈴」 | 建立在水準法上 | 久期做不出來（§7） |
| 「浮虧跟配息沒關係」／「有關係」 | 講的是不同段，沒說是哪一段 | §5.4：A 成立、B 斷、C 成立 |
| 「玉山四年皆無現金股利」 | 玉山印「股東紅利－現金」，regex 漏抓 | 2024 分配年配現金 40.0 億 |
| 「AC 吸收率」 | 我自己發明，分母近零時衝到 639% | 撤掉 |
| 「配置決定風險擺哪裡，不決定承擔多少」 | 建立在錯的久期上 | §0：三因子，方向對但理由錯 |
| 「債券總成長 vs CET1 = −1.00」 | 只在 AC+OCI 口徑成立，含 Trading 掉到 −0.10 | 用超額成長／Δ(債券/RWA)（§4.2） |
| 「資本薄 → 買公債（0% 權數）便宜擴表」 | 公債佔比 vs CET1 = **+0.50，反向**。玉山資本最薄、公債最少 | 推翻 |
| 「資本薄 → 用低權數資產便宜擴表」 | 實際是貨幣市場(0%)換債券(20~50%)，**消耗**資本 | 改為 reaching for yield（§4.5） |
| 「玉山不下大注、總風險最低」 | 只看利率風險 | 它的風險擺在信用那邊（§3「兩種風險是替代」） |
| 「玉山用信用風險**換掉**利率風險」 | 暗示它提高了信用曝險。實際非公債佔比五年只動 +1.4pt | 是別家在降（富邦 −8.7pt），**它沒跟著回頭** |
| 用加權平均風險權數當信用風險刻度 | 權數是我假設的，絕對值無意義 | 改用非公債佔比（零假設，排序相同） |
| **「報酬那一側做不出來，年報不拆債券利息」** | 19/20 份都單獨揭露證券利息 | 做得出來，見 §3.5 |
| **「五家殖利率幾乎相同（0.14~0.31pt）」** | 分母含了 Trading，而分子排除 Trading | 實際 0.37~0.66pt（§3.5） |
| **「最保守的兆豐殖利率最高，是低風險異象」** | 同上，Trading 佔比五家差 4.5%~29% | **完全相反**，兆豐連四年墊底 |

**方法教訓**
1. 基礎必須一致（個體 vs 合併混用兩次踩雷）
2. 不要用「只看一年」下全稱判斷
3. 複合變數要**先於**觀察
4. 逐年檢驗是最便宜的照妖鏡
5. **水準值 ≠ 變動值**
6. **恆等式改寫不是相關性**（§5.3 第一類）
7. 反推前先問「有沒有人已經算好並揭露了」——我做了三輪久期反推，
   而中信與兆豐的年報裡就印著答案
8. **相關係數活下來 ≠ 機制活下來**。§4 的 −0.60 通過所有穩健性檢定，
   但我為它提的機制連續死了兩個版本
9. **全體同向的東西，橫斷面測不出來**（§4.6 的競爭解釋）
10. **分子分母的口徑要對齊，而且錯了不會自己現形**。§3.5 的分母多放了 Trading，
    數字看起來完全合理（1.8~2.1%，量級對、逐年遞增也對），只是排名整個是反的。
    唯一抓到它的方法是去讀附註那句「上表不含透過損益按公允價值衡量之…」——
    **不是檢查算式，是回去讀分子的定義**。
11. **閘門與工單是一組的**，改了一邊要回頭看另一邊（§1 的兩列證券利息）。

## 11. 附錄：計算定義

### 共用符號

```
C = {AC, OCI, Trading}                         三個會計分類
K = {GB, 公司債, 金融債, 資產基礎, 其他}          有久期的券種
                                               ★ 排除「貨幣市場」與「股票」
P(c,k,t) = data.json["wide"][f"{t}|{銀行}"][f"{c}_{k}"]        公允/帳面價值,億元
Q(c,k,t) = data.json["wide_cost"][f"{t}|{銀行}"][f"{c}_{k}"]   取得成本,億元
```

**為什麼排除貨幣市場**：機制是「存續期間 → 浮虧 → 其他權益」，貨幣市場沒有存續期間、
不生浮虧，放進分母只是稀釋，而且**不均勻**（佔 AC 的 31%~88%，各家差很多）。
**為什麼排除股票**：權益工具不走這條機制，而且它的未實現利益會蓋掉債券浮虧
（兆豐 2024 股票 +196 億 vs 債券 −197 億）。

### 公式① 信用風險 = 非公債佔比

```
                    Σ(c∈C) P(c, GB, 2025H2)
非公債佔比 = 1 − ──────────────────────────────
                  Σ(c∈C) Σ(k∈K) P(c, k, 2025H2)
```

單一來源、單一時點、加總後相除。**沒有任何假設，可一行重算。**

例（國泰 2025）：分母 6,412 = 公債 2,326 + 金融債 1,170 + 公司債 1,541 + 資產基礎 1,375
→ 1 − 2,326/6,412 = **63.7%**

### 公式② 利率風險 = 總浮虧率（含 AC 隱藏）

```
              [FV(AC) − BV(AC)]  +  [Σ(k∈K) P(OCI,k) − Σ(k∈K) Q(OCI,k)]
總浮虧率 = ───────────────────────────────────────────────────────────────
                     Σ(k∈K) P(AC,k)  +  Σ(k∈K) P(OCI,k)

FV(AC), BV(AC) = 年報「非以公允價值衡量之金融工具」附註的公允價值與帳面價值
                 ★ 不在 data.json,由 PDF 逐頁查證抄出(§1 驗收 25/25)
Trading 不列入   ★ 它逐日透過損益評價,「未實現」對它沒有意義
時點 t = 2022H2  ★ 唯一有大利率衝擊的年;用 2025 各家都接近零,量不出差異
```

例（國泰 2022）：
```
AC  浮虧 = 揭露公允 4,863 − 帳面 5,139 = −277 億
OCI 浮虧 = P 1,888 − Q 2,049           = −161 億
分母    = AC債券 1,884 + OCI債券 1,888 = 3,772 億
        → (−277 − 161) / 3,772 = −11.60%
```

#### ⚠ ② 的分子分母基礎不同（設計選擇，非失誤）

```
2022年底   揭露帳面(分子基礎)   AC債券(分母)   其中貨幣市場   倍數
富邦            7,731億       4,696億      3,035億   1.65x
中信            9,422億       4,769億      4,654億   1.98x
國泰            5,139億       1,884億      3,256億   2.73x
玉山            3,981億       1,123億      2,859億   3.55x
兆豐              616億         617億      4,978億   1.00x  ← 只有它一致
```

分子是**整桶 AC 的浮虧（含貨幣市場）**，分母只有債券。
理由：貨幣市場幾乎零久期，浮虧全部來自債券，所以除以債券部位得到的才是債券跌幅。

**假設：貨幣市場浮虧 ≈ 0。敏感度**：若它其實跌 1%（國泰 3,256 億 × 1% = 33 億），
國泰 AC 跌幅由 −14.68% 變 −12.9%——**仍是最慘的一家，不影響結論**。

**改成「同基礎」反而更糟**：兆豐的揭露本來就排除貨幣市場（表前文字明講），
其他四家是全額。用揭露帳面當分母＝兆豐一套尺、別家另一套尺，排序會亂
（兆豐從第 4 跳到第 2）。現用的做法把五家統一到「有久期的債券」，才是一致的。

### 公式③ 承壓 = 到 11% 可跌

```
                (CET1率 − 11%) × RWA
到11%可跌 = ─────────────────────────      皆為 2025H2、個體口徑
                 Σ(k∈K) P(OCI,k)

CET1率 = capital.json 的 cet1 ÷ rwa（已過五道對帳，見 §1）
分母只放 OCI ★ AC 跌價不進 CET1
```

「AC 按市值後可跌」＝把 §6.3 的隱藏浮虧從 CET1 扣掉再算一次。

### 三個公式的性質

| | ① 信用風險 | ② 利率風險 | ③ 承壓 |
|---|---|---|---|
| 來源 | 只有 data.json | data.json **＋ PDF 抄讀** | capital.json + data.json |
| 假設 | 無 | 貨幣市場浮虧 ≈ 0 | RWA 不動 |
| 時點 | 2025 | **2022** | 2025 |
| 可重算 | 一行 | 需那 10 格 AC 公允價值 | 需 capital.json |

**①可以直接信；②要連同假設一起讀；③是保守值**（部位跌價會讓信用 RWA 跟著降，
實際緩衝比算出來的略大，但那只讓「資本線不會咬」更成立）。
