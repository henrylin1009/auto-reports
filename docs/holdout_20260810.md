# 保留集 2026-08-10

## 為什麼需要這個

`holdout.py` 原本那三格**已經全部進了 `facts/`**（其中兩格還跑過 revalidate
retries=2），所以目前**沒有任何工具能分辨「貼合這 58 份」和「通用」**。
所有「管線能動」的說法在換到新保留集之前都是回頭看的證據。

見 [[checks-must-fail]]：用完要換新的，不換就等於沒有。

## 抽法（先寫、後抽）

- **池子** = `pdf_cache/*.pdf` 減去 `facts/*.json`，共 33 份。**不縮小池子。**
  縮小就是挑軟柿子，那正是保留集要防的事。
- **種子** = `20260810`（當天日期，非事後挑選）
- **抽法** = `random.Random(seed).sample(sorted(pool), 3)`，`sorted()` 保證可重現
- **只抽一次。** 抽完不滿意不准換種子重抽 —— 換了這份文件的 git 歷史會顯示出來。

## 規矩

1. 跑之前**不看答案**，不逐頁翻 PDF 找數字。
2. 走正常管線（`/fill` 或 `v4/reader.py`），**不准為了讓它過而改任何檢查邏輯或
   `buckets.SYN`**。要改就是承認測驗失敗了，改完再抽新的一份。
3. 結果逐份記在下面「結果」段，**失敗也照記**。
4. 跑完這三份就算用掉了，之後它們進 `facts/`，下次要再抽新的。

## 判準

- **全綠** = 逐桶分得出來、總額/錨對得上、口徑判定正確，且沒有人工介入。
- 3/3 → 「管線能動」成立，往外做。
- 1–2/3 → 停止往外做。失敗那份直接指出缺口在哪一類（分桶／定位／取字）。
- 0/3 → 收回「通用」的宣稱，改成「五家銀行的專用管線」。

## 第一次抽籤作廢，重抽（2026-08-10，使用者裁示）

使用者裁示：**「舊的保留到資料庫就好，新的就是新的，幫我分開。」**
掃描影像檔屬於「舊」——本管線靠文字層運作，OCR 是另一個子系統。
它們不該出現在測「新東西」的保留集裡。

**新的池子定義：`pdf_cache` 減 `facts`，再排除零文字層者。33 → 25 份。**

這條規則是抽籤後才加的，誠實記錄在此。它之所以不算作弊：
(1) 不看任何答案就判得出來（只數字元數），(2) 判斷與結果無關。
但它畢竟是事後補的，後面看的人自己評估。

**排除的 8 份全是掃描檔，且不是隨機分布**：玉山(5847) ≤2020H1、國泰(5835) 2019–2020H1。
**從 `202004`（2020 年報）起，每一份都有文字層，無例外。**
→ 「舊/新」的界線不是拍腦袋的日期，是檔案自己的性質。

2018–2019 **有文字層的那 10 份仍留在池子裡** —— 它們是合法的「沒看過的年份版型」，
只有掃描檔被排除。縮小池子只縮到「管線原理上處理得了」為止，不再縮。
