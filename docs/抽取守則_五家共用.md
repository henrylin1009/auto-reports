# 銀行債券分類抽取守則（五家共用 · 給 LLM 的作業規格）

> 這份守則寫給「讀財報 PDF、抽債券分類明細」的 LLM 看。
> 不綁任何一家銀行、不寫死頁碼。五家（中信/兆豐/國泰/富邦/玉山）共用同一套流程，
> 明年新版財報、甚至新增銀行，原則上不用改。
>
> 已用 FY2024 年報（202404，各家民113/12/31）實測：15 格中 14 格直讀即過，
> 1 格（富邦 FVTPL）由第 3 條自動觸發翻附錄。

---

## 你要產出的東西

對「一家銀行 × 一期財報」，抽出**三張分類表**的**債種明細**（單位：仟元）：

- **FVTPL（交易，Trading）**：附註六(三)「透過損益按公允價值衡量之金融資產」
- **FVOCI（OCI）**：附註六(四)「透過其他綜合損益按公允價值衡量之金融資產」
- **AC（攤銷後成本）**：附註六(五)「按攤銷後成本衡量之債務工具投資」

（各家附註編號可能不同：國泰是「九」「十」，玉山是「九」「十」——**用標題文字定位，不要用編號**。）

每張表把各列歸到債種桶（見下方對照），並記錄該表的「小計 / 合計」供對帳。

---

## 流程（每一家都跑同一套）

### 第 1 步 — 找表（用標題關鍵字，不用頁碼）
在 PDF 全文找標題含以下關鍵字的段落：
- FVTPL：`透過損益按公允價值衡量之金融` + 表身有債種列
- FVOCI：`透過其他綜合損益按公允價值衡量之金融` + `債務工具`
- AC：`按攤銷後成本衡量之債務工具投資`

⚠️ **排除干擾表**：標題含「金融負債」「損益明細表」「證券部門…明細表（附錄逐檔）」「避險」的，都不是主彙總表。主彙總表的特徵是「債種列 + 金額 + 小計/合計」。

### 第 2 步 — 逐列歸類 + 對帳（護欄，最重要）
把每一債種列的金額歸到對應桶，然後：

```
各桶加總 + 衍生工具 + 評價調整 ≈ 表尾「小計 / 合計」
```

- **對得上（誤差 < 0.5%）** → 採用。
- **對不上** → 這格標 **N/A**，**不要猜、不要硬填**。（寧可缺，不可錯。）

> 對帳是這套方法的安全網：它保證「抽出來的加起來等於財報自己的合計」。
> 但它**只查總量、不查細分**——所以還需要第 3 條。

### 第 3 步 — 「其他」過大 → 翻附錄（**這條取代所有富邦式客製**）
若某桶「**其他**」金額 > 同一張表「小計」的 **15%**（或明顯大於其他真實債種）：

- **不要直接採用這個 lump 的「其他」。**
- 去找「**重要會計項目明細表**」附錄（常叫「明細表二/三/五」），把「其他」拆成真正的債種（公債/公司債/金融債/國庫券…）。
- 拆完後**用第 2 步再對帳一次**（拆出來的加總要等於原本那列的金額）。

> 這條不提任何銀行名字。FY2024 只有富邦 FVTPL 觸發（主附註把公債+公司債+金融債塞成「其他 163 億」）；其他四家的「其他」都是真雜項、不觸發。明年若別家開始偷懶，同一條自動接住。

### 第 4 步 — 亂碼先「詞座標重組」，真讀不出才標 N/A
`extract_text` 出現直排亂碼（字元被拆成一行一字的「字元湯」），**多半不是讀不出，是讀取順序被打亂**。處理順序：

1. **先詞座標重組**（通用、不分家不分年）：取 `extract_words()`，按每個詞的 y 座標（`top`）分列、同列內按 x 排序重組。直排亂碼會還原成正常的「品名 + 金額」表，再回到第 1~3 步照讀。
   - 已驗證：兆豐 2022/2023 年報 OCI/AC 主附註 `extract_text` 全是字元湯，重組後**完整還原、與 override 對帳吻合**（AC 逐格 100%；OCI 為毛額，與 override 淨額差即口徑差）。
2. **旋轉字（品名 90°）**：品名依 top 分列組字（x 有明顯左界，如 x<160），數值依 top 對齊取最右大數。
3. 真的是**掃描影像檔**（`extract_text` 字數 < 2000、根本沒有文字層，如 2020H1 國泰/玉山）→ 才標 **N/A**，不要硬填。

> 教訓：「`extract_text` 亂碼」≠「資料讀不出」。先做通用的詞座標重組，能救回絕大多數所謂「座標地獄」的表——這一步對五家、對各年都適用，不是逐年寫規則。

## 口徑決定（全五家必須一致）

### 毛額 vs 淨額（FVOCI 專屬）— **已定案：毛額**
FVOCI 彙總表的各債種列是**毛額**，表尾另有一列「評價調整」把它調到**淨額（公允價值）**：

```
債種列（毛額）  … 各桶       ← 【採用這層】直接讀各債種列
評價調整        （+/−）        ← 不分攤進各桶；單獨保留
小計 / 淨額     ← 毛額 ± 評價調整
```

**本專案一律用毛額**（= 取得成本/面額基礎，各家彙總可直讀、跨行一致、最省）。

規則：
1. 各桶 = 直接採 FVOCI 各債種列的數字，**不要**把「評價調整」分攤回各桶。
2. 「評價調整」那一列**單獨記錄**（供估值視角呈現含損/含益），不進債種桶。
3. **對帳照舊**：各桶（毛額）加總 + 評價調整 ≈ 表尾淨額/合計。

> ⚠️ **兆豐要改**：現有 `megabank_override.json` 的 FVOCI 是**淨額**（已把 −196 億評價調整分攤進各桶），與此定案的毛額不一致。要嘛改讀 FY2024 起可直讀的主附註彙總（毛額）、要嘛把 override 的 FVOCI 桶還原成毛額。其餘四家本來就是毛額，不用動。
> FVTPL/AC 不受此毛/淨之分影響。

### 單位
財報是**仟元**；成品用**億元**（÷1e5）。H2 取年報期末數（餘額類，不做相減）。

## 輸出格式（每家每期）

```json
{
  "bank": "富邦", "period": "2024H2",
  "Trading": {"公債": ..., "公司債": ..., "金融債": ..., "資產基礎": ...,
              "貨幣市場": ..., "股票": ..., "其他": ...},
  "OCI": { ... }, "AC": { ... },
  "_basis": "毛額",              // 定案：全批毛額
  "_recon": {"Trading": "ok", "OCI": "ok", "AC": "ok"},  // 或 "N/A"
  "_notes": "富邦 FVTPL『其他163億』觸發第3條→翻附錄明細表二拆為 公債25/公司債244/貨幣市場1244/其他50"
}
```
